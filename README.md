# Report Peepers

AI-driven, independent peer review of residential mold/moisture inspection reports for homeowners. Flat-fee review only: no pass/fail, no inspector scores, no upsells or referrals.

Status (2026-11-05): tested core, no web app, storage or payments yet. See `docs/HANDOFF.md`.

Start with `docs/spec/MASTER_SPEC.md`, then `docs/spec/DECISIONS.md`.
