# Report Peepers: working rules

Owner/decision-maker: Cory. Spec lives in `docs/spec/` (MASTER_SPEC.md is canonical).

- Preserve confirmed decisions C01-C10 in docs/spec/DECISIONS.md. Change technical defaults only via a written decision record.
- Plan first. No code without Cory's approval. Types check and tests pass before each next step.

- Never: contact inspectors, publish findings, deploy, connect payments, ingest protected standards, or train on customer documents.
- Keep requirement IDs (docs/spec/requirements.csv) stable.
- Workflow: use the Superpowers plugin (brainstorm, plan, test-first build, review).
